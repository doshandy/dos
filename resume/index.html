技术亮点

  • AI Copilot 交互设计：把 LLM 能力封装为可嵌入业务场景的侧边栏 Agent，支持会话上下文、SSE 流式输出、场景切换（查表 / 问血缘 / SQL 诊断）
  • 数据血缘可视化：基于 AntV G6 渲染大规模血缘图谱，支持拖拽、层级折叠、上下游影响链追溯
  • 低代码 → 源码工程化迁移：把数十个历史低代码页面批量转为 Vue 3 + TypeScript 源码，建立长期可维护的前端工程体系
  • 多国多业务线隔离：通过域名推断 + 运行时参数隔离，同一套代码支撑 CN / ID / ES / MX 多国独立部署
  • 细粒度权限体系：表级权限、用户分组、临时授权、审计流程
  • 大数据表格 / SQL IDE：VXE-Table 万行级数据流畅滚动；Monaco + sql-formatter 提供专业级 SQL 编辑体验（高亮 / 补全 / 格式化 / 执行计划）
