## 占位字段

简历里有少量 `{{}}` 占位需要替换为真实信息：

- `{{phone}}` 手机号
- `{{211 院校名}}` 本科学校
- `{{专业}}` 专业
- `{{2012 — 2016}}` 教育起止年

VSCode / Cursor 里 ⌘⇧F 搜 `{{` 一次性替换。

## 设计取舍

- **不写工作年限具体数字**：用「资深 / 多年深耕」等表达，避免和不同公司面试时口径冲突；面试时再具体说
- **不写公司全名**：用「某金融科技公司」+ 业务说明，敏感信息和行业可识别度兼顾
- **DataPilot 当主推、DataLumina 当并行**：保持 dos 项目的叙事一致性
- **KAP 单独成节**：作为可立即访问的"代码品质 + 工程化"自证
- **打印版做了浅色 + A4 单栏 @media print**：屏幕看暗色酷，打印时变标准简历，HR 收 PDF 不会觉得花哨
